# F1 ao vivo · GP de São Paulo 2026

Página única para acompanhar as posições da corrida no celular.

- **Dados:** placar público da ESPN, lido direto pelo navegador a cada 8 segundos.
- **Limite:** essa fonte não informa as diferenças de tempo entre os carros.
- **Fixo em `index.html`:** grid, números e cores dos carros do GP de 08/11/2026. Para outra corrida, atualizar `PILOTOS` e `VOLTAS`.
- **Publicação:** site estático no GitHub Pages, sem build e sem dependências.
